# 财务分析工具 v2.0 - 本地版

> 本地运行的财务分析工具，**全程不联网、不上传数据**，适合处理敏感商业财报。
> 支持多年趋势分析 + 自动生成 Excel 图表。

---

## ✨ v2.0 新增功能

- ✅ **多年财报支持** — 一次性分析 3 年（或更多）数据
- ✅ **趋势分析** — YoY 同比变化 + CAGR 复合增长率 + 趋势方向
- ✅ **自动图表** — openpyxl 原生图表（折线图、饼图），无需 matplotlib
- ✅ **多文件批量处理** — 自动按文件名识别年份
- ✅ **更丰富的报告** — 7 个 Sheet（首页/原始数据/财务指标/趋势分析/趋势图表/结构图表/数据校验）
- ✅ **v2.1 新增 7 个指标** — 利息保障倍数 / EBITDA 利润率 / 商誉净资产 / 账期 / 营收增长率 / 净利润增长率 / 归母净利润增长率
- ✅ **v2.2 作者名署名** — 报告首页显示「分析人: XXX」，报告文件名也带上作者名

## 🚀 快速开始

### 方式一：直接运行 .exe（推荐）

1. 双击 `财务分析工具.exe`
2. 点击「添加 PDF/Excel 财报」按钮，**可多次点击添加多个文件**
3. 文件名建议含 4 位年份（如 `2023年报.pdf` `2024年年报.pdf`），自动识别
4. 点击「开始分析」
5. 切换标签查看数据
6. 点击「导出 Excel 报告」保存

### 方式二：从源码打包

参考 `build.bat` 或：

```bash
pip install -r requirements.txt
pyinstaller --onefile --windowed --name "财务分析工具" ^
    --hidden-import PyQt5.sip ^
    --hidden-import openpyxl.cell._writer ^
    --collect-all pdfplumber ^
    --noconfirm main.py
```

## 📖 使用详解

### 文件名约定（强烈建议）

为了让工具自动识别年份，文件名最好含 4 位年份：

| 文件名 | 识别年份 |
|--------|----------|
| `2023年报.pdf` | 2023 ✅ |
| `平安银行2024年年报.pdf` | 2024 ✅ |
| `annual_report_2025.pdf` | 2025 ✅ |
| `某公司年报.pdf` | 未识别 ⚠️（会高亮提示） |

> 如果年份识别失败，请在 Excel 报告的 Sheet 名手动调整，或编辑代码扩展识别规则。

### 报告 Sheet 说明

| Sheet | 内容 |
|-------|------|
| **首页** | 报告封面、年份、生成时间 |
| **原始数据** | 三大报表数据，按年份并列 |
| **财务指标** | 30+ 指标 × 多年并列，分类展示 |
| **趋势分析** | 每个指标的 YoY 同比 + CAGR，绿色/红色高亮 |
| **趋势图表** | 折线图：营收/利润/利润率/ROE 多年趋势 |
| **结构图表** | 饼图：资产结构/资本结构/利润结构（最新一年）|
| **数据校验** | 资产=负债+权益等健康度检查，按年分组 |

### 支持的指标

- **盈利能力**（12 项）：毛利率、净利率、营业利润率、ROE、ROA、ROIC、EBITDA 利润率、各项费用率…
- **偿债能力**（8 项）：流动比率、速动比率、现金比率、资产负债率、权益乘数、长期资本适合率、利息保障倍数、商誉/净资产
- **营运能力**（9 项）：应收/存货/总资产/固定资产/流动资产周转率与天数、应收账款/营收
- **现金流**（5 项）：现金含量、自由现金流 FCF、资本支出比…
- **发展能力**（3 项）：营业总收入增长率、净利润增长率、归母净利润增长率
- **杜邦分析**（4 项）：ROE 三因子分解

> 总计 42 项指标（含多年趋势的 YoY + CAGR）

### 趋势分析包含

- **YoY 同比**：相邻两年的变化百分比，↑/↓/→ 方向箭头
- **CAGR 复合增长率**：3 年数据自动计算（如 2023→2025 算 2 年 CAGR）
- **颜色高亮**：增长为绿色 🟢，下降为红色 🔴

## 🛠️ 常见问题

### Q1: 启动时报"缺少 xxx.dll"

**A:** 安装 [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

### Q2: 扫描件 PDF 解析为空

**A:**
- 工具不内置 OCR（保持 .exe 体积）
- 建议先用 [Adobe Acrobat](https://www.adobe.com/acrobat/pdf-to-word.html) 或
  [百度网盘 PDF 工具](https://pan.baidu.com/) 转成文字版
- 或手动把数据填到 Excel 模板里

### Q3: 趋势图表在 Excel 里看不到

**A:**
- 必须用 **Microsoft Excel** 打开（不是 WPS/Google Sheets）
- 图表在「趋势图表」和「结构图表」Sheet 里
- 如果版本较老（<2010），需要升级

### Q4: 多年财报分开放还是合并成一个 Excel？

**A:** 都支持：
- **多文件**（推荐）：每份财报一个 PDF/Excel，按年份分开传
- **单文件多年**：一份 Excel 含多个 Sheet（如 "2023资产负债表" "2024资产负债表"）

### Q5: 想加新行业（银行/保险/地产）的科目

**A:** 编辑 `analyzer.py`：
- 在 `BS_ITEMS` / `IS_ITEMS` / `CF_ITEMS` 加新科目和同义词
- 在 `calculate_indicators()` 加新公式
- 重新打包

### Q6: 报告里图表位置奇怪

**A:** openpyxl 图表锚定用相对位置。打开后可以拖动调整，工具不影响数据。
